# Чек-лист сервиса на AD

## 1. До патча
- [ ] Сервис отвечает.
- [ ] Checker зелёный.
- [ ] Сделан бэкап (код + конфиг + БД).
- [ ] Известен endpoint, который проверяет checker.
- [ ] Известен формат флага и где он лежит.
- [ ] Есть команда отката.

## 2. Патч
- [ ] Изменён только уязвимый участок.
- [ ] API не изменён.
- [ ] Патч протестирован локально.
- [ ] Патч не ломает аутентификацию.
- [ ] Секреты не попали в код.
- [ ] Логи не отключены.

## 3. После патча
- [ ] Сервис перезапущен.
- [ ] Checker зелёный.
- [ ] Функциональность проверена вручную.
- [ ] Флаги не текут.
- [ ] Логи пишутся.
- [ ] Есть время на откат.

## 4. Откат
```bash
# пример
kubectl rollout undo deployment/<name>
# или
cp -r /backup/<service> /service/<service>
kubectl delete pod <pod>
```

## 5. Красные флаги
- Checker красный > 2 минут.
- Сервис отдаёт 5xx.
- Патч затронул больше 1 файла.
- Нет бэкапа.
- Никто не понимает, что изменилось.
