# Шпаргалки: индекс и порядок использования

Восемь рабочих документов на один экран каждый — не учебник, а «открыл перед задачей и пошёл по шагам». Все файлы лежат в этой папке, написаны под формат X Кубка CTF России 2026 и проверены по задачам 2020–2025.

> **Правило:** шпаргалка помогает выбрать следующий шаг, но не заменяет чтение условия и исходников задачи. Команды с адресами, версиями и путями всегда сверяй с конкретным окружением.

## 2. Порядок для отбора (jeopardy, 24 часа)

Не читай все восемь подряд. Двигайся по типу задачи:

| Ситуация | Первый файл | Дальше |
|---|---|---|
| Дали URL или API | `web.md` | `misc_osint_ppc.md` (если есть бот/OSINT), `forensics.md` (логи/PCAP) |
| Дали бинарь и nc | `pwn.md` | `reverse.md` (если нужно понять проверку), `privesc.md` (если это машина) |
| Даны числа/шифры | `crypto.md` | `reverse.md` (если крипта внутри бинаря) |
| Даны pcap/дамп/диск | `forensics.md` | `misc_osint_ppc.md`, `crypto.md` |
| Даны APK/.NET/VM/Go/Rust | `reverse.md` | `pwn.md` (если есть удалённый сервис) |
| «Просто автоматизируй» | `misc_osint_ppc.md` | `pwn.md` (pwntools), `crypto.md` (математика) |

**Три прохода по задачам:**

1. **10 минут:** прочитать все условия, открыть шпаргалку только для непонятной категории, отметить 3–4 быстрых задачи.
2. **Основная работа:** держать открытой одну шпаргалку по текущей категории; после каждого шага записывать команду и вывод.
3. **Последние 30 минут:** проверить формат флагов, отправить всё найденное, дописать writeup по шаблону `../templates/writeup_template.md`.

## 4. Соглашения и плейсхолдеры

| Обозначение | Значение |
|---|---|
| `$H` | Хост атакуемой команды в AD |
| `$S` | Свой хост/сервис |
| `$J` | Жюри/чекер-система |
| `$T` | Team token |
| `IP`, `ATTACKER`, `LHOST` | Адрес атакующего |
| `PORT`, `LPORT` | Порт сервиса/слушателя |
| `TEAM\d{3}_[A-Z0-9]{32}` | Формат флага AD в репозитории 2025; на игре проверяй фактический regex |
| `ctfcup{...}` | Формат флагов отбора; регистр и скобки копируй из условия |

Все команды с `example.com`, `10.10.10.5`, `0x401000`, `NTHASH`, `{CLSID}` — шаблоны. Подставляй свои значения и проверяй, что инструмент установлен (`command -v`).

## 5. Как поддерживать шпаргалки в рабочем состоянии

1. **После каждой тренировочной задачи** добавляй 3–5 строк в конец соответствующего файла: задача → техника → команда/payload → грабли. Не переписывай теорию.
2. **Проверяй команды на своей машине.** Особенно Windows-команды в `privesc.md` и `ad.md`: часть утилит (`accesschk`, `winpeas`, `PrintSpoofer`) может отсутствовать или блокироваться Defender.
3. **Фиксируй версии.** `pwntools`, `angr`, `Volatility 3`, `impacket`, `nuclei` меняют CLI. Если команда не запускается — смотри `--help`, а не гадай.
4. **Не храни в шпаргалках реальные флаги, токены и пароли** от игровых серверов. После финала удали или замаскируй.
5. **Одна задача — одна запись.** Дублирование техник в разных файлах допустимо, но правило должно быть одно: `web.md` — про web, `privesc.md` — про повышение привилегий.
