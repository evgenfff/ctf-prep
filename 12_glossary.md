# 12. Глоссарий

Минимум терминов, чтобы вся команда говорила на одном языке. Термины сгруппированы по темам.

---

## Форматы и организация

| Термин | Значение |
|---|---|
| **CTF** | Capture The Flag — соревнование по информационной безопасности. |
| **Jeopardy / task-based** | Формат «задачи + флаги»: команда решает задания и сдаёт ответы. |
| **Attack-Defense (AD)** | Формат, где команды одновременно защищают свои сервисы и атакуют чужие. |
| **Multi-machine pentest** | Формат, где нужно последовательно скомпрометировать несколько машин. |
| **Флаг** | Строка-ответ, обычно `ctfcup{...}`. |
| **Чекер (checker)** | Программа, которая проверяет работоспособность сервиса и наличие флагов. |
| **SLA** | Service Level Agreement — доступность сервиса; в AD за неё дают/снимают очки. |
| **Скорборд** | Таблица результатов команд. |
| **Динамические очки** | Стоимость задачи падает с ростом числа решивших. |
| **Cutoff** | Порог очков/мест для прохода в следующий этап. |
| **Writeup** | Разбор решения задачи. |
| **Unintended** | Решение, не предусмотренное автором, но приводящее к флагу. |
| **Revenge** | Усложнённая версия уже решённой задачи. |

## Web

| Термин | Значение |
|---|---|
| **IDOR** | Insecure Direct Object Reference — доступ к чужому объекту по ID без проверки прав. |
| **SSRF** | Server-Side Request Forgery — сервер делает запрос по URL, который контролирует атакующий. |
| **XSS** | Cross-Site Scripting — выполнение чужого JS в браузере жертвы. |
| **CSRF** | Cross-Site Request Forgery — выполнение действия от имени жертвы. |
| **CSP** | Content Security Policy — заголовок, ограничивающий источники скриптов. |
| **SQLi** | SQL-инъекция. |
| **NoSQLi** | Инъекция в NoSQL-хранилище (MongoDB и т.п.). |
| **SSTI** | Server-Side Template Injection. |
| **LFI / RFI** | Local/Remote File Inclusion. |
| **RCE** | Remote Code Execution. |
| **JWT** | JSON Web Token. |
| **OAuth / OIDC** | Протоколы авторизации/аутентификации. |
| **Prototype pollution** | Загрязнение прототипа объекта в JavaScript. |
| **Request smuggling** | Контрабанда HTTP-запросов через рассинхронизацию парсеров. |
| **WAF** | Web Application Firewall. |
| **Headless browser** | Браузер без интерфейса; часто используется для PDF/скриншотов и может ходить по внутренним URL. |

## Pwn

| Термин | Значение |
|---|---|
| **Pwn** | Эксплуатация бинарных уязвимостей. |
| **Canary** | Случайное значение на стеке для защиты от переполнения. |
| **NX** | Запрет исполнения данных на стеке/куче. |
| **PIE** | Position-Independent Executable — случайная база бинаря. |
| **ASLR** | Address Space Layout Randomization. |
| **RELRO** | Защита GOT; Full RELRO делает GOT read-only. |
| **ROP** | Return-Oriented Programming — сборка цепочки из гаджетов. |
| **ret2libc** | Возврат в функцию libc (обычно `system`). |
| **ret2win** | Возврат в функцию `win`, которая печатает флаг. |
| **SROP** | Sigreturn-Oriented Programming. |
| **FSOP** | File Stream-Oriented Programming. |
| **Heap / tcache** | Куча и её кэш для быстрых аллокаций. |
| **UAF** | Use-After-Free. |
| **Double free** | Повторное освобождение чанка. |
| **TOCTOU** | Time-of-Check to Time-of-Use — гонка между проверкой и использованием. |
| **OOB** | Out-of-Bounds — выход за границы буфера. |
| **KASLR** | Рандомизация адресов ядра. |
| **modprobe_path** | Глобальная переменная ядра, перезапись которой даёт выполнение кода. |
| **Seccomp** | Фильтр системных вызовов. |
| **ORW** | Open-Read-Write — шеллкод, читающий флаг без `execve`. |
| **cve-rs** | Демонстрация UB в Rust через lifetime extension. |

## Crypto

| Термин | Значение |
|---|---|
| **RSA** | Асимметричная криптосистема на факторизации. |
| **Bleichenbacher** | Атака на padding oracle в RSA PKCS#1 v1.5. |
| **Hastad** | Broadcast-атака при малом `e`. |
| **Wiener** | Атака на малую приватную экспоненту. |
| **Coppersmith** | Поиск малых корней модульного многочлена. |
| **LLL** | Алгоритм решётки, применяется к subset sum/knapsack. |
| **Knapsack** | Рюкзачная криптосистема. |
| **Meet-in-the-middle** | Перебор с двух сторон, ускоряющий 2^n до 2^(n/2). |
| **DLP** | Discrete Logarithm Problem. |
| **Pohlig-Hellman** | Решение DLP в группе с гладким порядком. |
| **ECC** | Криптография на эллиптических кривых. |
| **p-адики** | p-адические числа; используются в задачах на модульную арифметику. |
| **PRNG** | Псевдослучайный генератор. |
| **MT19937** | Вихрь Мерсенна, предсказуемый после 624 выходов. |
| **Padding oracle** | Утечка информации о корректности паддинга. |
| **CRC** | Контрольная сумма; иногда нужно восстановить прообраз. |
| **HLE** | Hash Length Extension. |
